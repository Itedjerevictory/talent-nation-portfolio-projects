In Python, this organized container is called a List. A list allows you to store multiple items inside a single variable. You can access individual items by pointing to their specific number positions (called Indexing), or grab a subset of items at once (called Slicing).

For this entire lesson, we will use a single physical scenario: a wooden flavor rack with slots, five colored syrup bottles, and small cardboard label tags for the slot numbers. Through this setup, you will learn how to create lists, access individual syrups using 0-based indexing, slice out sets of flavors for custom stations, and avoid the classic trap of the index error.
